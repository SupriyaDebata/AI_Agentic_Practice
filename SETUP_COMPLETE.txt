==============================================================================
QUALITY GATE CONFIGURATION
==============================================================================

Default Thresholds (configurable in src/config.py):
- Faithfulness: 0.85 (min 85% grounding)
- Answer Relevancy: 0.80 (min 80% relevance)
- Context Precision: 0.75 (min 75% precision)
- Context Recall: 0.75 (min 75% recall)
- Citation Accuracy: 0.90 (min 90% accuracy)
- Hallucination Score: 0.85 (min 85% no hallucinations)
- Retrieval F1: 0.70 (min 70% F1 score)
- Answer Semantic Similarity: 0.75 (min 75% similarity)
- Grounded Refusal: 1.0 (must refuse unknown answers)

Pass/Fail Logic:
- PASS: ALL metrics meet or exceed thresholds
- FAIL: ANY metric falls below threshold

==============================================================================
KNOWN LIMITATIONS & NOTES
==============================================================================

1. Metrics require LLM calls
   - First evaluation ~30-60 seconds (model warmup)
   - Subsequent evaluations faster (metric calculation only)

2. Memory usage
   - 8GB RAM minimum recommended
   - ChromaDB grows with document size
   - Reports stored as JSON files

3. Dependencies
   - Requires Ollama running locally
   - Python 3.11+ required
   - No external API keys needed

4. File Storage
   - Datasets stored as JSON (evaluation/datasets/)
   - Reports stored as JSON (evaluation/reports/)
   - ChromaDB stored as local directory (chroma_db/)
